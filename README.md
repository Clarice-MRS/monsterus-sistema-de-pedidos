# MONSTERUS

Projeto de desenvolvimento web de um restaurante fictício inspirado no universo de Lady Gaga.

O projeto apresenta um sistema de cardápio e pedidos, permitindo que o usuário escolha entre Delivery ou Peça e Retire, selecione produtos, monte seu carrinho e visualize o resumo do pedido.

## FUNCIONALIDADES

- Visualização do cardápio.
- Filtro de produtos por categoria.
- Cardápio em formato de carrossel.
- Controle da quantidade de cada produto.
- Adição de produtos ao carrinho.
- Armazenamento do carrinho utilizando `localStorage`.
- Remoção de produtos do carrinho.
- Cálculo automático do subtotal.
- Cálculo da taxa de entrega.
- Cálculo do valor total do pedido.
- Escolha entre:
  - Delivery;
  - Peça e Retire.
- Cadastro dos dados necessários para pedidos por Delivery.
- Escolha da unidade para pedidos de retirada.
- Possibilidade de alterar ou zerar o pedido.
- Confirmação do pedido.
- Página com informações sobre as diretrizes do projeto.
- Página "Trabalhe Conosco".
